# くらしのレシート v0.9 — 無料の学習・予測

Android / Windows 共通のPWAです。v0.8の**食費内訳円グラフ**、v0.7の日付入力改善、v0.6の月別配分、OCR、個人用Supabase同期を引き継いだ更新版です。

## 今回追加した機能

### 1. 修正学習（追加の有料AI・追加のVision呼び出しなし）

- 履歴の「購入全体を編集・明細を分割」から、商品名・統一名・大分類・小分類を直して「変更を保存」すると、**学習する**のチェックが有効な場合、元の読み取り名と修正先を学習します。
- 次回、同じOCR商品名（全角・半角・空白などの表記差は正規化）を検出したとき、名前、統一名、分類を自動補正します。
- 学習ルールはログイン先のSupabaseに保存。PCとAndroidで共通に使えます。権限のないユーザーには読み取れないRLSを設定します。
- 今回の「ムセンアカフジ5kg」など**以前に訂正済みのお米**は「学習・予測 → 既存履歴から学習」を押すと、分類済みの購入履歴から登録できます。
- ルールには「忘れる」操作があります。元の購入履歴は削除されません。
- 誤補正を防ぐため、学習からの**曖昧な類似名の自動適用は行いません**。初めて見る製品には既存の固定ルールを適用します。これは生成AIやモデル自体の再学習ではなく、**ルールベースの記憶・補正**です。

### 2. 予測・参考情報（全てブラウザ内の統計計算）

- **月別支出・食費の参考予測**：対象月以前の最大6か月のうち、データがある月が2か月以上あれば、その平均と観測範囲を表示。集計には**計上月**を使用します。
- **商品の価格参考情報**：同じ統一商品名・単価単位で2件以上の履歴があれば、最新・平均・最安の単価を表示します。
- **次回の計上月の配分提案**：同じ商品で2件以上の計上月配分があり、配分傾向が一致する場合に提示。購入履歴の編集画面に「過去の配分から提案」ボタンがあります。**提案を押さない限り変更しません**。
- 履歴が少ない時は「データ不足」を表示します。これらは予測・参考値であり、将来の支出や販売価格を保証しません。

## 必須更新手順（必ず順番に）

1. **現在の家計簿で「設定 → JSONバックアップを書き出す」** を行い、ファイルを別の場所にも保管してください。
2. このZIP内の `learning-migration.sql` の全文を、現在のSupabaseプロジェクトの **SQL Editor** に貼って一度実行します。正常なら `Success. No rows returned` となります。既存購入履歴を変更・削除しない追加テーブルです。
3. ZIPを展開し、Webアプリ用のファイル（`index.html`, `app.js`, `cloud.js`, `editor.js`, `learning.js`, `receipt.js`, `ocr-parser.js`, `style.css`, `sw.js`, `manifest.webmanifest`, `icon.svg`, `icon-192.png`, `icon-512.png`）を、既存GitHubリポジトリ `highllows-stack/receipt-ledger` の `main` ブランチ直下にアップロードし、同名ファイルを置き換えます。**ZIP自体や `learning-migration.sql` はGitHub Pagesへアップロードしないでください。**
4. `https://highllows-stack.github.io/receipt-ledger/?v=0.9` を開き、画面に「学習・予測 v0.9」と表示されることを確認します。古い画面なら `Ctrl + Shift + R` で再読込します。サイトデータ削除はしないでください。
5. Supabaseにログインし、「学習・予測 → 既存履歴から学習」を押して過去の訂正済み履歴を読み込みます。**先に誤分類を修正してください。**
6. 「学習済み」の件数が表示されたら、他の端末でも同じアカウントでログインし、学習ルールが見えるか確認します。

## データと料金

- **外部の有料AI APIを追加しません。** 商品の学習と予測は無料のJavaScript処理と、既存Supabaseデータベース内のテーブルで動きます。新しいEdge Functionや追加のVision API呼び出しはありません。
- Supabase無料枠のストレージ・通信の制限内なら追加利用料金はありません。無料枠を超えた場合の運用や、すでに利用中のGoogle Cloud Vision OCRの課金は別途管理が必要です。「全サービスが無制限に無料」という意味ではありません。
- 学習ルールは、個人用・共有用の**家計簿単位**で保存します（共有用の操作画面・招待は今後対応）。同じユーザーでも権限のない家計簿のルールは見られません。
- 購入履歴、月別配分、画像OCR、既存データベースに破壊的な変更を加えません。
- JSONバックアップには現在の学習ルールのスナップショットも含めます。ただしクラウド上の学習ルールを復元する専用操作は未実装です。クラウド復旧時は既存履歴から学習し直すことができます。
- レシート画像の30日保管、家計簿の共有招待、OCRの一般的な誤字認識を再学習する高度なモデルは未実装です。

## 確認済みの範囲

- ローカル模擬データによるPC／スマホ相当画面テスト、学習ルールの追加・削除・再使用、月別予測・価格比較のテスト。
- Supabaseとの通信はブラウザでモック検証済みですが、**利用中の実際のSupabaseでのSQL適用とPC／スマホ同期は更新後に確認が必要**です。
