# くらしのレシート v0.7 — 日付欄のクリック操作・円グラフ表示

Android / Windows 共通PWA。v0.6の月別計上・数量按分・購入履歴・Supabase同期・OCRの仕組みは引き継ぎます。

## 改善内容

- 日付／年月入力（対象月、購入日、計上月、編集欄）では、**カレンダーアイコンだけでなく数字・文字が表示された部分をクリック／タップ**してもOS・ブラウザのネイティブ日付選択を開きます。対応するブラウザでは `showPicker()` を使用し、非対応環境は標準操作へ戻します。キーボード Enter / Space にも対応します。
- 「集計 → 費目別の支出」で **棒グラフ／円グラフを切り替え**できます。
- 円グラフは大分類または小分類を選択できます。分類名、金額、割合(%)を併記します。
- 円グラフも購入月／計上月、対象月、家計簿切替に連動します。データなしは空表示にします。
- 棒グラフと大分類→小分類→明細の展開、6か月推移は引き続き利用できます。
- グラフ表示モードと円グラフ分類レベルをブラウザ内に記録します。購入データとは別の設定値です。

## 更新方法

1. 先に現行版の **設定 → JSONバックアップを書き出す** を実行してファイルを保管します。
2. このZIPを解凍し、**Webアプリ用ファイル**を `highllows-stack/receipt-ledger` の `main` ブランチのルートにアップロード、同名ファイルを置換します。ZIPそのものをアップロードしないでください。
3. GitHub Pages反映後、`https://highllows-stack.github.io/receipt-ledger/?v=0.7` で開き、画面に「円グラフ・日付操作改善 v0.7」と表示されることを確認します。必要なら `Ctrl + Shift + R` で再読み込みします。
4. 「集計」の対象月欄の年月部分をクリック → カレンダー表示と、円グラフの切り替えを確認してください。

## Supabaseについて

**今回のv0.7だけなら追加SQL・Edge Function更新・Google Cloud再設定は不要**です。まだv0.6の月別計上SQLを実行していない場合は、v0.6の `allocation-migration.sql` の実行が先に必要です。

既存のSupabaseの購入データは変更しません。なお、GitHub Pagesのキャッシュ更新や別端末での動作確認までは、既存バックアップを残してください。
