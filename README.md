# くらしのレシート v1.3 — レシート明細判定・数量・税込照合／保存画像の90°回転

前のv1.2を引き継いだAndroid・Windows対応Webアプリです。既存の月別配分、食費グラフ、Supabase同期、学習・予測機能をそのまま残しています。

## 今回の実物レシートを使った回帰テスト

2026年10月23日、maruetsu目黒店の写真と登録結果を確認しました。

- **商品は9行、購入点数は11点**。キャベツガリバタは「149円×3個＝447円」で、1行・数量3個です。
- 商品の税抜合計は **1,600円**。すべての商品の「※」印と軽減税率の注記により **8％の外税128円**。レシートの税込合計 **1,728円** と一致。
- 「小計」「11点」「8%外税対象額」「8%外税額」「合計」「お預り」「お釣り」「POINT番号・残高」「レジ番号・店舗番号」「電話番号・登録番号」は商品ではありません。
- 読み取った商品名の先頭の3桁の売場コードを商品名から除外します（例: 「333 かぼちゃ」→「かぼちゃ」）。
- 元の登録画面に見える **14,422円は誤読による金額**であり、決して正解ではありません。更新しただけでは履歴は自動書換えしないため、必ず下記の「修正方法」で直してください。
- 税抜1,600円を9商品へ税込金額として按分すると、レシート全体の税額128円に合わせて端数を調整します。印字されない商品別税込額は、税率ごとの合計からの**按分値**であり、メーカー表示の個別価格ではありません。

## 修正内容

1. **小計以降は一切商品抽出をしない**レジ締め後セクション判定。文字が改行分割される場合も除外。
2. ポイント番号、電話番号、店舗・レジ番号等の支払いメタデータは、商品名＋数値に見えても除外。
3. `(@149 × 3(個))` は直前の447円明細に数量3個として結びつけ、別商品としない。
4. 読み取り品目数の合計と印字点数、税抜小計、税額、税込レシート合計をそれぞれ照合し、一致しない場合は「要確認」。勝手に合計差額を商品として追加しません。
5. レシートに「※印は軽減税率適用商品です。」の注記があれば、※印の明細は8％として扱い、印字税額の按分に使用。
6. 編集画面に **左90°、右90°、回転をクラウドに保存**を追加。回転は写真の実ピクセルを変え、クラウドへ再保存するため他端末でも同じ向きになります。30日保存期間は回転保存日から更新されます。
7. OCRテキストを解析するボタンはVision再呼出し不要。保存写真が読みにくい場合は「保存写真を再OCR」で**利用者が明示的に同意した場合のみ**、Visionの追加呼び出し1回を行えます（Google Cloudの無料枠やトライアルを超えると費用が生じる可能性があります）。再OCRした原文は、購入編集画面の「変更を保存」を押すまでDBには保存されません。

## 初回インストール／v1.2からのアップデート

1. **「設定」からJSONバックアップ**をダウンロードし、必要ならCSVも保管してください。クラウド履歴がJSONに全件入っているとは限らないため、同期状態も確認してください。
2. このZIPを解凍し、中の15ファイル（ZIPそのものではなく中身）を `https://github.com/highllows-stack/receipt-ledger/upload/main` にアップロードして `Commit changes`。
3. GitHub Pagesの更新後に `https://highllows-stack.github.io/receipt-ledger/?v=1.3` から開き、画面上に「点数・税額照合と写真回転 v1.3」と表示されることを確認。
4. 10/23の誤登録を「履歴」→「maruetsu」→「購入全体を編集・明細を分割」で開く。
5. 写真が横向きなら「右90°」→「回転をクラウドに保存」。写真を見ながら「OCR原文から明細を再作成」を押す（**この再解析は無料、追加Vision呼出しなし**）。
6. 原文の読取り自体が足りない場合にのみ、必要なら「保存写真を再OCR」で**追加Vision 1回の料金可能性を了承**して再実行。その後「OCR原文から明細を再作成」。
7. 商品9行、数量11点、税込1,728円になっているか、カテゴリや個々の計上月・配分も確認して「変更を保存」。間違った既存行は置換操作で消える可能性があるため、必ず確認してください。

## 設定・費用・制約

- **v1.1の写真保存SQLと `receipt-ocr` Edge Functionが設定済みなら追加SQL・Edge Function更新は不要です。** `cloud.js` の既存公開キーだけを使用し、秘密鍵は公開しません。
- 画像の90°回転はブラウザのCanvasとSupabase Storageを使用。追加の有料AIは使用しません。既存のGoogle Vision OCRには通常の料金枠が適用されます。手動の写真再OCRは明示的に開始する場合のみ1回余分に呼び出します。
- 紙レシートと読み取り原文が完全に一致する保証はありません。商品ごとの税率と税額が印字されていないレシートでは、税込按分は参考値です。
- JSONバックアップにはクラウドの全履歴が含まれない場合があります。特に重要な購入履歴はCSVも保管してください。
- 本版のパーサーは実レシートから転記したテストケースと分割行のモックで検証済み。画面はネット接続のないPC・スマホ模擬環境で確認済みですが、実際のGoogle VisionとSupabaseでの保存・同期は本番環境での確認が必要です。
