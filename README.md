# くらしのレシート v0.1（初期プロトタイプ）

Android / Windows PC 用 PWA の基礎版です。日本語 UI。

## 今できること
- 個人用・共有用の**端末内**家計簿切替と追加
- 手入力で複数の商品を1件の購入として登録
- 商品別の大分類・小分類、数量、容量、産地、冷凍/冷蔵の記録
- 月別のカテゴリ別支出集計
- レシート（購入）単位 / 商品単位の履歴切替、検索、金額と商品名の簡易編集、購入削除
- 統一商品名による価格比較（30日/90日/1年/全期間/任意期間）と属性フィルター
- JSONバックアップ・復元、CSVエクスポート
- レシート画像のカメラ撮影・複数ファイル選択UI（OCR処理は**未接続**）

## まだできないこと（次の開発段階）
- Google Cloud Vision OCR・自動商品分類/登録・画像保存/30日後の自動削除
- Supabase 認証・スマホ/PC間同期・家族招待・共有権限
- アプリのクラウド公開・継続的なアップデート配信
- 編集画面でのカテゴリ/属性変更、値引き・税・ポイントの精密なレシート照合
- 安全なクラウドバックアップとDBマイグレーション

**重要：** 現在の保存先はブラウザの localStorage です。ブラウザデータを削除すると消失します。端末間同期もしません。JSONバックアップを定期的に保存してください。将来のクラウド版は別途データ移行処理を実装する必要があります。JSON形式は schemaVersion 付きです。

## Windowsで試す
1. ZIPを展開。
2. `index.html` をChromeで開くと手入力・集計などを試せます（`file://` ではPWAインストール不可）。
3. PWAとして試すには、Pythonがインストールされている場合、展開したフォルダで `python -m http.server 8000` を実行し、Chromeで `http://localhost:8000` にアクセスします。

## Androidで試す
PCで公開用HTTPSホスティング（例：Cloudflare Pages / GitHub Pages）にフォルダの中身を配置し、Android Chromeで公開URLを開きます。Chromeのメニューから「ホーム画面に追加」または「アプリをインストール」を選びます。**この段階では公開URLにアクセスしてもデータ同期はしません。**

## 次の開発に必要な準備
- Supabaseプロジェクト（無料枠）、Google Cloud Vision API（請求先登録と利用制限の設定）
- HTTPSホスティング先（無料枠利用を検討）
- 認証・行レベルセキュリティ（RLS）、API秘密鍵をサーバーで保持する仕組み

APIキー・サービスアカウントの秘密鍵はHTML/JavaScriptに直接記載しないでください。
