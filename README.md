# くらしのレシート v0.3

Android/Windows PWA。Supabase認証＋個人用家計簿の手入力同期に対応。

## 更新
このフォルダ内のファイルを GitHub `receipt-ledger` リポジトリのルートへアップロードし、同名ファイルは置き換えてください。GitHub Pages の公開が更新されたら両端末でアプリを再起動します。

## ログイン
アプリの「設定」からメールアドレス＋パスワードで「新規登録」を実行。メール確認が有効な場合はメールのリンクを開き、ログインしてください。同じアカウントでPC/Androidからログインしてください。

## データの扱い
以前のデータは端末内（localStorage）にそのまま残ります。ログイン後に「この端末の個人用履歴をクラウドへ取り込む」を手動実行できます。最初に「JSONバックアップを書き出す」をお勧めします。クラウドデータがあるときにJSONを直接復元しないでください。クラウドでは既存のローカルデータを自動削除しません。

## 未対応
レシートOCR、複数利用者による共有家計簿、クラウド画像保存・30日自動削除、クラウドの商品名統一ルール同期、クラウド家計簿切替、オフラインでのクラウド書込み、同時編集の競合処理。

## セキュリティ
ブラウザに含まれるのは Supabase の公開用 publishable key のみです。service_role/secret key やDBパスワードを配置しないでください。データベースRLSによって本人の行だけを保護します。メール確認設定とSQL実行状態を確認してください。
