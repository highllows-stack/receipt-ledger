# くらしのレシート v1.6 — 税率注記からの自動税込計算・印字合計との照合

Android/Windows向けPWA。v1.5の写真確認・回転・手動補正・月別配分・価格比較・学習/予測等を維持します。

## 新機能

- OCR原文の「※印は軽減税率対象商品」等を解析。印の付いた商品は8%、商品行の「10%」等も解釈。
- 商品ごとの税抜価格を合計し、レシートの小計・印字税額・税込合計・購入点数と照合します。印字税額と合計が確認できるときは税を明細に自動配分し、重複登録を防ぎます。
- OCRが税込合計を読めないが、商品小計と印字税額が確認できるときは参考税込合計を自動算出して登録（要確認）。
- ※印・小計が明確だがOCRで税額と合計を読み取れない場合は8%の参考額を算出（要確認）。
- 商品別に「税率と推測根拠」「加算税額」「税込額」を編集画面の照合欄に表示。
- 過去のレシートも「税率・税込を自動判定して明細を再作成（無料）」を押すと、保存済みOCR原文を再解析。写真の再OCRはVisionを追加利用するため別操作。
- 不一致時は数字を適当に合わせず「要確認」にし、元のレシート写真と手入力で修正できます。

## v1.5 からの更新

1. 旧アプリで「設定 → JSONバックアップを書き出す」を押し保存。
2. ZIPの中身15ファイルをGitHubリポジトリ `highllows-stack/receipt-ledger` のmainルートへアップロードし Commit changes。ZIPファイル自体はアップロードしません。
3. https://highllows-stack.github.io/receipt-ledger/?v=1.6 を開き「税率注記・自動税込計算 v1.6」を確認。
4. 今回のmaruetsuの履歴を開き「税率・税込を自動判定して明細を再作成（無料）」を試す。OCR原文に税額等が残っていない場合は、保存写真の再OCR（Vision利用・無料枠に注意）か、既存の手動補正を使用。

追加SQLやEdge Functionの変更は必要ありません。既存レシート・計上月配分を更新時に一括書き換えません。写真・原文に無い税率を確定したと主張せず、OCR情報が足りないときは要確認とします。

## テスト

Node.jsで正規化・税抜8%・税込内税・合計欠落時の推定・混合税率・税額不一致・明細行数/点数の検査を実行します。実際のSupabase+Google Vision連携での最終検証は使用中の環境で必要です。
