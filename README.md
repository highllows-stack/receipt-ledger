# くらしのレシート v2.0 — OCR証拠の保存・商品行補完・レシート金額照合

Android / Windows 共通 PWA。v1.9からの累積更新です。学習、非公開写真保存、画像回転、各商品専用電卓、税額計算、g/kg/本/個/分数の月別配分は残しています。

## この版の改善

1. **合計金額の誤読防止**: OCRの「合計」候補を、小計＋印字税額、またはお預り−お釣りと比較します。合致しない場合、たとえ「合計」と読めてもその金額を確定しません。
2. **OCR位置情報も保存**: Google Visionで通常の文字列と同時に得ている行位置情報を、今後のレシートではOCR原文とともに非公開の既存 `receipt_ocr_text` フィールドへ保存します。再解析時には双方を比較し、**実際にOCRで検出された商品行**のうち証拠に合うものを選びます（追加のVision呼び出し不要、SQL変更不要）。以前の履歴は位置情報が保存されていないため、過去のOCR本文だけでは失われた文字を取り戻せません。
3. **OCRの誤字や読み落としを無料で訂正**: 履歴編集画面の「OCRが読み取った原文を表示」→「OCR原文の文字を訂正して無料で再解析する」で、写真を見ながら原文を補って再照合できます。「明細を再作成」→「変更を保存」の操作前は履歴を更新しません。
4. **2026/10/24 マルエツの写真照合済み修正を再表示**: 「税込699円」（豚肉384円＋誤ってプラス商品になった割引116円＋ウインナー199円）などの誤登録でも、該当日・店舗・商品名・金額の組合せに一致すれば専用修正ボタンを表示します。写真で確認した豚肉税込289円・キャベツ118円・ウインナー215円、税込合計622円を候補として表示します。別の購入には適用しません。最後に利用者が保存するまでは変更しません。
5. **根拠が足りない場合は「要確認」**: OCR本文で2明細・308円しか検出できないとき、3点・小計576円と合わないことを警告し、商品を推測だけで捏造しません。
6. **v1.9の編集機能を維持**: 各商品の税込金額欄直下の電卓、分数と使用量の月別按分などは引き続き利用可能です。

## 更新手順

1. 既存アプリの「設定」→「JSONバックアップを書き出す」を行い、別ファイルとして保管します。
2. このZIPを解凍し、Web用の**15ファイル**（index.html、app.js、receipt.js、ocr-parser.js、editor.js、style.css、cloud.jsほか）だけを `https://github.com/highllows-stack/receipt-ledger/upload/main` でアップロードし、**Commit changes** を押します。ZIPファイルそのものや、このZIP外の開発用テストコードはアップロードしません。
3. Pagesへの反映後 `https://highllows-stack.github.io/receipt-ledger/?v=2.0` を開き、画面上部に「OCR証拠保存・商品行補完・合計照合 v2.0」とあるか確認します。旧版が残る場合はCtrl+Shift+RかPWAの完全再起動を行います。**ブラウザデータは消さないでください。**
4. 該当購入を「履歴 → 2026/10/24 Amaruetsu → 購入全体を編集」で開き、「10月24日のレシートを写真照合済み3商品・税込622円に修正」を押します。税込622円／3商品を確認し、「変更を保存」を押します。ボタンが出ない場合は、写真を見ながら明細を豚肉289円・キャベツ118円・ウインナー215円に修正し、レシート合計622円を設定してください。

## 注意事項・検証

- 今回は既存データベース構造・RLS・Google Cloud / Edge Functionは変更しません。追加SQLや有料AI APIは必要ありません。
- 画像のOCRを新たに実行する場合は従来のGoogle Vision無料枠・料金条件が適用されます。**無料のOCR原文再解析は追加Vision呼び出しをしません。**
- 2026/10/24 のレシートを再現した14ケースの解析テスト（合計候補誤読、預り・釣銭、商品読み落とし、レイアウト行救済、旧履歴との互換など）を実施。PC/スマホ幅のブラウザで、699円の編集内容から622円の修正候補、個別電卓、OCR原文編集／再解析、新規登録時の位置情報の保存形式を確認。
- **実際に利用中のSupabaseでの同期・Google Visionの読み取り結果そのものは未検証**です。OCRが商品名自体を読めない場合は、保存写真からの手動補完か再OCRが必要です。
